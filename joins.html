Why Join UMC / 为什么选择同心

Professional Growth / 专业成长

Inclusive Culture / 温馨氛围

一个充满活力、支持创新、像家一样温暖且尊重多元文化背景的团队。

Official Certificate / 官方认证

为加入我们的高中生与大学生志愿者提供官方认可的社会实践义工小时证明及高质量推荐信。

Current Openings / 开放机会

After-School Mandarin Teacher (校内课后中文主讲老师)

Part-Time Hourly Rate / 按时薪酬 📍 San Francisco (SFUSD 校区内)
Apply Now / 立即申请

Core Responsibilities / 核心职责：

  • 负责 K-5 年级课后沉浸式中文课程的日常教学、教案实施与班级管理。
  • 设计寓教于乐的语言游戏与文化拓展活动（如农历新年、中秋节等传统项目）。
  • 维护与合作学校校长、公立学校班主任以及学生家长的日常良好沟通。

Requirements / 任职要求：

  • 具备母语级的标准普通话听说读写能力，发音标准，无明显地方口音；持有“普通话水平测试（PSC）”等级证书者更佳。
  • 具备流利的英语沟通能力，以确保与学区校园及家长的顺畅对接。
  • 热爱幼儿/小学教育，充满活力，对孩子有耐心，并具备良好的班级秩序管理能力。
  • 有美国本地课后托管（After-School）或沉浸式语言学校教学经验者优先。
  • 须通过法定的背景调查，包括 Livescan 指纹检查及肺结核（TB）体检证明。

After-School Teaching Assistant (课后托育助教)

Part-Time Hourly Rate / 按时薪酬 📍 San Francisco (SFUSD 校区内)
Apply Now / 立即申请

Core Responsibilities / 核心职责：

  • 协助主讲老师进行日常的学生接托（Campus Pickup），确保学生从日校教室到课后班的安全过渡。
  • 辅导学生的常规英文/数学家庭作业，协助分发每日健康点心。
  • 在中文沉浸式环境中配合主讲老师，协助维护课堂秩序及学生在校安全。

Requirements / 任职要求：

  • 具备良好的中英双语沟通能力，能听懂并进行基础的普通话交流。
  • 有责任心、准时守时、乐于与儿童互动，具备良好的团队协作精神。
  • 须通过 Livescan 指纹背景调查及肺结核（TB）体检。
